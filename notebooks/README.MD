<h1>Дипломный проект по программе "Машинное обучение и высоконагруженные системы".</h1>

</h2>Идентификация искусственно сгенерированных текстов: разработка методов для обеспечения информационной достоверности.</h2>

</h2>Identification of Artificially Generated Texts: Development of Methods for Ensuring Information Authenticity.</h2>

<h3>В текущей директории находятся ноутбуке с исследованиями, созданием датасета, обучением модели</h3>

1. Загрузка (парсинг) и обработка оригинальных новостей

2. Генерация новостей (на основе оригинальных)

3. Генерация новостей по заголовкам

4. Финальный этап подготовки данных

5. Базовый подход к детекции LLM сгенерированных новостей

6. Обучение моделей детекции LLM сгенерированных новостей
