<h1>Дипломный проект по программе "Машинное обучение и высоконагруженные системы".</h1>

</h2>Идентификация искусственно сгенерированных текстов: разработка методов для обеспечения информационной достоверности.</h2>


</h2>Identification of Artificially Generated Texts: Development of Methods for Ensuring Information Authenticity.</h2>


В рамках текущего репозитория выполнена практическая часть ВКР по созданию сервиса направленного на идентификацию ИИ сгенерированных новостей. Здесть представленны ноутбуки по соберу, обработке данных, построению алгоритмов, развертыванию сервиса и все остальное, связанное с задачей ВКР.

<h3>Содержание.</h3>

**notebooks** В директории находятся ноутбуки с исследованиями, созданием датасета, обучением моделей (архитектур) идентификации LLM сгенерирвоанных новостей. На основе этих ноутбуков написана ВКР о сервисе идентификации.
